# Отчёт сравнения naive и ReAct

Сравнение выполнено через локальный LM Studio endpoint
`http://127.0.0.1:1235/v1` с API identifier `gpt-5.4-mini`. Для каждого
сценария выполнена ровно одна попытка naive и ReAct; сырые stdout/stderr
сохранены без ручного редактирования в `docs/archive/agent-react-results/`.

## Наблюдения

- Ни одной ревизии `REVISE` не применилось, поэтому утверждать, что reflection
  улучшил ответы, нельзя. В трёх RAG-сценариях ReAct дошёл до critic, но общий
  15-секундный бюджет завершился `Timeout`; превышений `max_iterations` не было.
- В сценарии времени оба агента ответили корректно и вызвали только
  `get_current_time`. ReAct потратил 2402 токена против 1575 у naive: critic
  вернул `OK`, не улучшив уже корректный результат.
- В RAG-сценариях 1 и 3 naive использовал `search_knowledge_base`, опёрся на
  fallback-фрагмент и завершил ответ. ReAct не дошёл до финального ответа, так
  что влияние улучшенных tool descriptions на выбор инструмента по этим raw
  traces подтвердить нельзя. В stderr зафиксированы неуспешные обращения RAG к
  Qdrant/Hugging Face перед локальным fallback.
- В сценарии 4 naive дошёл до финального текста, но CLI завершился
  `UnicodeEncodeError` при печати JSON trace с Unicode-символом. Полный trace не
  попал в stdout, поэтому шаги и токены отмечены `н/д`, а отправка не считается
  подтверждённой успешной. ReAct завершился `Timeout`.
- На провокационном вопросе оба агента корректно ответили без инструментов.
  Naive использовал 916 токенов, ReAct — 1181; critic не вызывался, поскольку
  observation отсутствовал.

## Средние значения

- Среднее число шагов naive: **1,75** (по 4 числовым результатам).
- Среднее число итераций ReAct: **1,20** (по 5 результатам).
- Среднее число токенов naive: **1587,75** (по 4 числовым результатам).
- Среднее число токенов ReAct: **1266,40** (по 5 результатам).
- Суммарное число применённых ревизий: **0**.
