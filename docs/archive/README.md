# Архив материалов курса

Этот каталог содержит исторические эксперименты, промежуточные отчёты и сырые
результаты домашних заданий. Они сохранены как доказательная база, но не
описывают актуальную production-архитектуру проекта.

Крупные сохранённые документы:

- [`course-history.md`](course-history.md) — исходный course-by-course README;
- [`architecture-course-design.md`](architecture-course-design.md) — учебный ADR с future Redis/LiteLLM;
- [`agent-persistent-report.md`](agent-persistent-report.md) — отчёт блока 6.4 с историческими counts;
- [`telegram-bot-course-report.md`](telegram-bot-course-report.md) — ранний bot-отчёт;
- agent/benchmark/security подкаталоги — raw traces и comparison artifacts.

Активная карта документации: [`../README.md`](../README.md).
